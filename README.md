# AEROULTRA Pool Console (S1 Pool)

全栈号池调度、多级联盟与实时遥测控制台（前端 React 19 + Vite 6 + TypeScript，后端 Express + SSE 实时流推送 + 自动种子初始化存储）。

## 核心功能模块

- **禅意暗黑登录与多角色权限体系 (`/login`)**：支持超级管理员 (`admin`)、可开下级的大联盟商 (`supplier`)、子联盟商 (`supplier`) 与只读审计员 (`observer`) 四类权限视图，支持中英双语切换及右下角演示身份一键切入。
- **运筹帷幄 · 指挥总览 (`/overview`)**：引擎实际/健康 RPM 超载波形图、宿主机队 (`ATHENA01` ~ `HYPERION05`) CPU/内存/VM 实时遥测与接单开关、5h/7d 配额窗口分布及账号/联盟产值排行。
- **俯瞰全局 · 号池主控台 (`/pool`)**：鸟瞰状态矩阵、桌面互动像素宠物 (`Mascot`)、5h / 7d / Sonnet 三窗口配额条、多维状态筛选（已启用 / 已限流 / 故障 / 已禁用 / 部署中 / 部署失败）、住宅代理巡检延迟、批量启停删打标、账号详情抽屉 (`AccountSheet`)、**幽灵山谷 (`GhostValley`)** 前世产值结转，以及五步 **OAuth 账号部署向导 (`DeployDialog`)** 与全局上号通道开关。
- **联盟版图 (`/hierarchy`)**：一级/大联盟商与子联盟商层级树、结算倍率配置、下级开户授权、托管联盟区与密码重置。
- **继往开来 · 金色结算台账 (`/settlement`)**：基于 `BigInt` 分级精度的应收/应付/待结/多付核算、付款记账、财务流水抽屉与单笔冲正撤销 (`undo`)。
- **广而告之 · 实时公告台 (`/notices`)**：基于 SSE 实时统计在线控制台页面数，支持立即/定时发布顶部跑马灯公告、撤下与重发。
- **明察秋毫 · 请求计费溯源 (`/usage`)**：多维条件检索请求日志，自动关联承接账号与宿主机 `VM` 编号，抽屉展开输入/输出/5m 与 1h 缓存单价快照及计费公式拆解。

## 环境要求

- **Node.js**：`>= 20.0.0`（推荐 `Node.js 22 LTS`）
- **npm**：`>= 10.0.0`

## 快速启动

```bash
# 1. 安装依赖
npm install

# 2. 启动前后端开发服务（后端 :3456 + 前端 :5173）
npm run dev
```

Windows PowerShell 环境下也可直接运行启动脚本：

```powershell
.\start-dev.ps1
```

启动后浏览器访问：`http://127.0.0.1:5173/pool`

> 首次启动时，`server/store.ts` 会在本地自动生成 `data/db.json` 仿真演示数据（`data/` 已加入 `.gitignore`，不会提交任何本地运行状态或会话记录）。

## 生产构建校验

```bash
npm run build
```
